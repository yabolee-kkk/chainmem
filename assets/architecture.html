ChainMem Architecture

Chain + Vector Hybrid Memory System — Ingestion / Retrieval / Storage

Ingestion

  • • text → chunk → embed → link → store
  • • Incremental indexing (132ms, new nodes only)
  • • sentence-transformers embedding model
  • • Tag-based classification support

Retrieval

  • • FAISS semantic search (TOP-10)
  • • Substring match bonus (+0.20)
  • • Tag filtering (OR logic)
  • • next_id chain traversal → 100% fidelity

Performance

  • • Query: ~22ms
  • • Incremental add: ~132ms
  • • Startup: ~1s (disk cache)
  • • MCP server: non-blocking (asyncio)
